国界线折纸

机器学习 · 一张三维纸，折出乌兹别克斯坦

还是这张纸，还是这面粉色阈值面——只是这次纸不是用来判 A/B，而是用来贴国界。目标是乌兹别克斯坦：费尔干纳谷地那圈毛刺，加上中间嵌着的塔吉克斯坦飞地。

每按一次折，就给网络加一个隐藏单元，也就是纸面上多一道折痕。折痕可以竖折、斜折、横折；压到阈值面以上的部分算"国内"，沉下去的是"国外"。折痕一道道叠上去，纸上高出来的那一片就慢慢变成这个国家的形状。

一道折痕，就是纸面上的一个坡

纸面高度是这么算出来的：每道折痕贡献一个 ReLU 坡，坡的方向是法线 aᵢ，位置由 cᵢ 决定，深浅是 wᵢ：

h(x) = b + Σᵢ wᵢ · ReLU(aᵢ·x + cᵢ)　，　国内 = { x : h(x) > 0 }

粉色那张平面就是 h = 0 的阈值面。纸面穿过阈值面留下的一道闭合交线，就是折出来的国界——金色那条。真实国界是粉色虚线，直接铺在纸面上，方便你比它差多少。

折痕数 = 隐藏单元数。你每按一次「折一下」，就多一个神经元；加进来之后所有折痕的深浅会整体重解一次（加权最小二乘），不是一道一道单独调。

为什么能折出飞地：只往下压（w 全是负的）只能切出凸形，切不出"国内夹着一块国外"。必须允许某些折痕的 w 是正的，把一小块重新抬起来——一抬一压，纸面上就出现一个坑。这就是 ReLU 网络能表达非凸区域的原因：正负权重混在一起，h = 0 的交线可以拐弯、可以闭合。
飞地是这张纸上最小的东西（索赫只有整张纸宽度的百分之三），网格上就那么几格，折到四十几道也只勉强凹进去一块——这一块正是最难折对的地方。

三个能看出来的东西

① 只有直边能被一道折痕贴住。国界里每段直的边，都能被一道折痕严丝合缝地压住；弯的地方只能靠几道短折痕拼——折痕越多，交线越像。
② 前几折都在抢大轮廓。重叠率从 21% 冲到 60% 很快，剩下十几个百分点全花在费尔干纳谷地和飞地上。
③ 折痕会互相改。新加一道折痕后，老折痕的深浅会跟着变，有的甚至从"往下压"翻成"往上抬"。不是一刀定终身，而是所有折痕一起重新分工。
