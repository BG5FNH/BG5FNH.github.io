感知机 整棵树的中点：最小的学习节点 —— 给一组输入，乘权重、求和、过阈值，输出 0 或 1

1958 年 Rosenblatt 的感知机只有一层，却第一次让机器"从数据里调参数"：猜错了就按误差方向挪一点权重。它只能划一条直线，所以被 XOR 卡住；但把它叠起来、把阈值换成可导的函数，就是今天的深度学习。

线性模型

逻辑回归

把感知机的硬阈值换成 sigmoid：输出变成 0–1 的概率，损失变成交叉熵，就能用梯度下降稳稳地训。工业界最常见的基线之一。

它和感知机的区别只有一个：阈值可导 → 能算梯度 → 能叠很多层。

sigmoid交叉熵正则化

SVM / 核方法

不找"任意一条分界线"，而找"间隔最大的那条"。线性分不开时用核函数把样本映射到高维，等价于在原始空间画曲线。

最大间隔核技巧软间隔

反向传播 → 深度网络

多层感知机（MLP）

把感知机叠成层、换成可导激活函数（ReLU / tanh），理论上就能逼近任意连续函数。真正的难点是"怎么训练"，答案是反向传播。

隐藏层万能逼近ReLU

反向传播

链式法则 + 计算图：前向算出预测，反向把误差一层层乘回去，得到每个权重的梯度。深度学习能跑起来，靠的就是它 + GPU。

梯度消失/爆炸，本质是雅可比连乘的数值后果。

链式法则计算图自动微分

CNN / RNN

CNN 用卷积利用"局部相关 + 平移不变"，把图像参数量降几个数量级；RNN 按时间展开处理序列，LSTM 的门控缓解长依赖。

卷积感受野BPTT

注意力 / Transformer / 大模型

自注意力让任意两个位置直接相连，不再受序列长度限制：Attention(Q,K,V) = softmax(QKᵀ/√d)·V。堆很多层 + 海量数据，就有了今天的大模型。

自注意力位置编码预训练 + 微调

学习范式

监督学习

有标签。两条主力：线性/逻辑回归做基线，树模型（决策树 / 随机森林 / GBDT / XGBoost）做表格数据。表格题先上树模型，通常比神经网络省事。

无监督学习

聚类不是"分类的弱版"，它回答的是另一个问题：这些样本自己会分成几堆。

理论根：图灵机

图灵机

1936 年那个"一条纸带 + 一个读写头"的抽象机器。它划定了"什么能被机械地计算"的边界——感知机、神经网络、大模型，全都活在这条边界里面。

纸带状态转移丘奇-图灵论题

可计算性与自动机

停机问题不是"难"，是"不存在这样的程序"；有限状态机 → 下推自动机 → 图灵机，能力一层层变强。正则表达式、词法分析、协议状态机，都是这条线上的产物。
