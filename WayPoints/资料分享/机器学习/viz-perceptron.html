感知机 · 折纸动画

机器学习 · 可视化 · 一张纸怎么学会分开苹果和蓝莓

把一张纸看成"所有可能的物体"：横轴是颜色（左边很蓝 = 蓝莓，右边很红 = 苹果），纵轴是大小（下面小，上面大）。纸上每一粒点就是一个物体。

感知机做的事，就是在纸上折一道折痕：折痕一边判"蓝莓"，另一边判"苹果"。一开始折痕是随便折的（随机方向、随机位置），之后每喂一个点，判错就把折痕挪一点——挪到两堆点中间为止。

苹果（红、偏大） 蓝莓（蓝、偏小） 刚被喂进去的点 判错的点（折痕会因此挪动）

判对时折痕不动；判错时折痕朝"把这个点划到正确那一边"的方向挪一小步——这就是感知机学习规则。 一直喂到不再判错，折痕就停止不动了，训练结束。

它到底在算什么

把每个物体写成两个数：x₁ = 颜色（越大越红）、x₂ = 大小（越大越大）。感知机只有三个参数：权重 w₁、w₂ 和一个偏置 b。

判断： w₁·x₁ + w₂·x₂ + b > 0 ? 苹果 : 蓝莓
判错时修正： w ← w + η·y·x ，b ← b + η·y （y = +1 苹果 / −1 蓝莓，η 是步长）

那道"折痕"其实就是方程 w₁·x₁ + w₂·x₂ + b = 0 画出来的直线：它的方向由 (w₁, w₂) 决定，位置由 b 决定。所谓训练，就是不断改这两样东西。

  1. 随机取一个方向和一个位置 —— 折痕先随便折一下；
  2. 喂一个点进去，用当前折痕判它是苹果还是蓝莓；
  3. 判对了什么都不做；判错了，把这个点的坐标按方向加进权重里，折痕就会朝它转过去一点；
  4. 重复很多次，折痕会停在两堆点中间 —— 因为只要还有点被划错，它就会被推走。

为什么它一定会停下来（以及什么时候不会）

如果两堆点能被一条直线分开（线性可分），感知机一定能在有限步内找到一条分界线——这是 1962 年的感知机收敛定理。

但如果两堆点混在一起（比如有些蓝莓特别大、或者颜色重叠），它永远停不下来：折痕会被来回推。这也是当年 XOR 问题把感知机钉住的原因——单层感知机划不出"异或"那种交叉分布。把折痕折两次（多层），才解决这件事。

这页的绿色"重新随机"按钮会重新撒点并重新折一张纸；你也可以看着折痕被某个顽固的点来回推——那就是"不可分"的样子。
