Transformer 与大模型

机器学习 · 科技树 · 18 个节点

▶ 先看动图：自注意力　·　位置编码　（视觉实验室全部）

2017 年之后几乎所有进展都在这棵子树上：自注意力 → 多头 → 位置编码 → 预训练范式 → 大模型 → 对齐与高效微调。

← 回到 机器学习总览

Transformer 核心

只用注意力，不用循环：并行、可堆深、能吃海量数据。

出处：Vaswani et al., NeurIPS 2017

自注意力 核心

Attention(Q,K,V)=softmax(QKᵀ/√d)V，任意两位置直连。

多头注意力

多组 QKV 并行，学不同的关系子空间。

位置编码

注意力本身无序，位置信息要显式加进去（正弦 / RoPE）。

BERT

双向掩码预训练，NLP 进入“预训练 + 微调”时代。

出处：Devlin et al., 2018

GPT 系列 核心

自回归预测下一个 token，规模上去后涌现出通用能力。

出处：Brown et al., 2020

T5

把所有任务统一成 text-to-text。

ViT

图像切 patch 当 token，数据够多就能打过 CNN。

出处：Dosovitskiy et al., ICLR 2021

Swin

窗口注意力 + 层次结构，兼顾分辨率与速度。

CLIP

图文对比学习，把两种模态映射到同一空间。

出处：Radford et al., 2021

Whisper

弱监督大规模语音识别。

LLM 核心

十亿到万亿参数，规模 + 数据 + 对齐共同决定能力。

指令微调 SFT

用指令-回答数据把“续写器”变成“助手”。

RLHF

用人类偏好对齐输出；DPO 省掉奖励模型。

出处：Ouyang et al., 2022

LoRA

只训练低秩旁路，显存降一个量级。

出处：Hu et al., 2021

RAG

外挂知识库，把“记不住”变成“查得到”。

MoE 混合专家

每个 token 只激活部分专家，参数大但算力省。

KV 缓存

位置外推、稀疏注意力、KV 压缩，都是为了让上下文更长。
