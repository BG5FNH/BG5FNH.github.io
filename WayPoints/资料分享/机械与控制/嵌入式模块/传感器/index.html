传感器

资料分享 · 机械与控制 · 嵌入式模块

传感器选型只看四件事：测什么量、接口是数字还是模拟、量程与精度够不够、要不要标定。下面按最常用的四类分开写，每类给几个常见型号与坑。

温度六轴光敏气体

温度

型号接口量程 / 精度取舍
DS18B20单总线（1-Wire）−55~+125 °C，±0.5 °C（−10~85）一根线可串多个，线长几米也稳；转换要等（12 位约 750 ms）
DHT22 / AM2302单总线（私有协议）−40~80 °C，±0.5 °C；湿度 ±2%RH温湿一体的便宜方案；采样不能快于 2 s，时序对中断敏感
NTC 热敏电阻模拟（分压）看 B 值与电路，常见 −40~125 °C几毛钱，但要自己换算 + 标定；线性度差
热电偶 + MAX6675/31855SPI0~1024 °C（K 型）高温场合唯一选择；需要冷端补偿，精度不如上面几种

坑：把 DHT 类传感器放在主控旁边，读到的其实是板子的温度；测环境温度要离开热源、留风道。

六轴（加速度 + 陀螺）

型号接口特点取舍
MPU-6050I²C3 轴加速度 + 3 轴陀螺，内置 DMP最便宜的入门件；老、假货多，零漂需要静态标定
MPU-9250 / ICM-20948I²C / SPI九轴（加磁力计）能算绝对航向；磁力计极易被电机/喇叭干扰
BMI270 / LSM6DS3I²C / SPI低功耗、噪声小可穿戴/电池设备首选；资料比 MPU 少

坑：六轴只能算「相对姿态」，长时间积分一定漂；要稳定姿态得上「加速度 + 陀螺」互补滤波或 Kalman，要绝对航向再加磁力计并做椭球标定。

光敏

型号接口特点取舍
GL5528（光敏电阻）模拟（分压）亮阻 ~10 kΩ、暗阻 ~1 MΩ最便宜；响应慢（几十 ms）、一致性差，只适合「亮/暗」判断
BH1750I²C直接输出 lux，量程 1~65535 lx要读数就用它；有窗口/遮光罩影响很大
TEMT6000模拟光电晶体管，近似人眼响应做「环境光自适应背光」够用，仍要标定

坑：光敏电阻的阻值与照度是对数关系，直接当线性值用会「白天差别不大、晚上跳变」；要分段或取对数。

气体

型号测什么接口取舍
MQ-2可燃气体（LPG/丙烷/氢气/烟雾）模拟 + 数字阈值便宜、灵敏度高；不能给浓度，只能做报警阈值，需预热
MQ-135空气质量（CO₂/NH₃/苯等综合）模拟同上，输出是「相对变化」，不是 ppm
SGP30 / SGP40TVOC / eCO₂（算法估算）I²C数字输出、体积小；eCO₂ 是估算值，不是真实 CO₂ 浓度
MH-Z19CO₂（NDIR 真测）UART / PWM能出 ppm；贵、体积大、需要定期基线校准

坑：半导体气体传感器（MQ 系）对温湿度极敏感，读数会随季节漂；要么做温湿度补偿，要么只用它做「有没有」的判断。真要 ppm，选 NDIR 或电化学。
